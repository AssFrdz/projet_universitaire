Install and run instructions

Principle of the software

Marmote consists of a C++ library and its wrapping to Python. Programming in either language is made easier using the following technologies:

  1. Conda is used to create execution environments which are consistent with the chosen version of Marmote.

    1. Please note that there are no commercial restrictions with our use of conda.

    2. marmote only uses packages from channel conda-forge which is an open source channel managed by the community.

    3. marmote is open-source and hosted on an open-source channel.

    4. the choice of miniforge insures the use of softwares or packages with no commercial restrictions.

  2. CMake is used for C++ progamming as the primary build system generator. It configures the build environment and generates platform-specific build files (e.g., Makefiles, Visual Studio project files).

Versions and prerequisites

The current version of Marmote is 1.3.1.

Versions 1.3.0 and 1.2.0 can still be used but are not recommended.

Version 1.1.1 and version 0.3.0 are deprecated.

Requirements for Python programming are:

  • Versions 1.3.0 and 1.3.1

    1. depend on python 3.10 or 3.11 or 3.12 or 3.13

    2. depend on numpy 2.X

  • Version 1.2.0

    1. depends on python 3.10 or 3.11

    2. depends on numpy 1.2X.

Requirements for C++ programming are:

  • Versions 1.3.0 and 1.3.1

    1. depend on GLIBC 15

In case of problems

Although we have tested the environment on many platforms, you may encounter some difficulties. If this is the case,

  • please take a look at the dedicated troubleshooting page

  • or contact us if your problem persists.

Note that in order to make our conda environment as portable as possible, we have chosen not to overload it with numerous installed packages. Most of the time, the problem originates in a missing package, or a mismatch between package versions. In that case, you will just need to (re)install a specific package to resolve the situation.

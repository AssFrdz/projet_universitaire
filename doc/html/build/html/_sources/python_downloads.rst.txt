**JANI** translator

Here is a link `to the programming project <https://github.com/bellkilo/pAI2D_mdp_languages>`_ of two `AI2D <https://androide.lip6.fr/>`_ Master's students (Zeyu TAO and Jiahua LI) that we supervised. This project provides a jani translator to marmote object: from a jani file we can build a Marmote Object (MDP, MC).

`Jani <https://jani-spec.org/>`_  is a  modelling language of Markovian processes for verification and model checking. There are a number of model files available `on the benchmark website <https://qcomp.org/benchmarks/>`_ (mainly of them are designed for the study of *reachability* and therefore contain some absorbing states).
